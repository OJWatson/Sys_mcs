Ready for code review: scripts prepare nine country rows (six PDFs found, three missing), copy 354 verified no-DOI PDFs, and update 336 existing records. Production Sheets, production PDF storage and sharing permissions have not been changed.

This report supersedes the earlier assumption that all 395 recovered filenames were suitable for PDF-found updates. Identity checks held 41 records, including 37 of the original 373 live matches.

Methods

This is a deterministic record audit, not a fitted statistical model. Inputs were the committed 521-record no-DOI recovery manifest and DOI results, all 395 local PDFs synced from the recovery folder, source bibliography, the protocol draft, the 15-candidate HRP review and read-only production snapshots. PDF checks used file signatures, size, MD5/SHA-256, conservative title matching and page-level review of exceptions, including OCR for scanned material. Seven records were remapped to exact entries in other existing abstract books; the original source provenance remains recorded. Program-only listings, unrelated versions, generated text and unresolved title/abstract conflicts were held.

Country review used actual study populations, locations, mortality evidence and publication version. The protocol overlap rule selected final article 39727 instead of preprint 124095; its source file named 124095.pdf contains the final article. The runnable manifest restores records to full-text screening. Reviewer decisions, assignments and comments are blank on new rows. Full-text screeners still adjudicate crisis relevance, HRP timing, population and all remaining eligibility criteria. The draft protocol and screening-code ambiguity are recorded limitations.

Both scripts default to read-only planning. Apply authenticates the operator, rechecks IDs, titles, source checksums, source and destination inventories and physical sheet columns, then copies or reuses files and updates exact cells. It preserves decisions/comments and handles both pdf_link columns. Conflicts or detected concurrent edits stop the run. Copy attempts and exact changes are recorded in timestamped receipts. No sharing calls are made. Reruns do not duplicate matching files or records; operators must run one apply at a time.

Discussion

A filename alone is insufficient evidence of successful retrieval. A verified abstract or poster can count as a retrieved document, but this does not establish a full journal article or protocol eligibility. Related later publications and program-only title listings are not substituted for exact records. The 41 holds remain explicit, with evidence in the inventory, rather than being marked found.

Validation does not eliminate uncertainty about source cataloguing or final study eligibility. The real integration used the Google connector to execute R-generated requests, while the R OAuth adapter was tested with mocked responses; an authenticated end-to-end R run has not been claimed. The connector did not expose remote MD5, so integration checksum fixtures came from verified local bytes. The production R adapter requires fresh remote MD5 and size before copying. Raw reviewer snapshots and publisher PDFs are excluded from the PR.
